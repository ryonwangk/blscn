# BLS Captcha 逆向分析报告

> IP 解封后可继续使用 `blscn_captcha_solver_v2.py`

## HAR 文件

`har/spain.blscn.cn_2026_05_20_10_30_15.har`

## 验证码类型

**点击选图验证码（Select Tiles by Number）**

- 指令格式: `Please select all boxes with number 123`
- 每次请求生成随机 3-6 个目标数字
- 共 54 个候选格子

## 关键发现

### 1. 图片格式
- **JPEG base64 格式**（`/9j/4AAQ` = JPEG magic header）
- 每张图片约 500-2000 字节
- 每个格子有随机 div ID（如 `qeshnw`, `kutkb` 等 5-15 位）
- 图片是通过 `onclick="Select('qeshnw',this)"` 绑定点击事件

### 2. 验证码 JS 逻辑（内联在 GenerateCaptcha 响应中）

```
var selection = [];
function Select(id, img) {
    if (selection.indexOf(id) > -1) {
        // 取消选中
        selection = jQuery.grep(selection, value => value != id);
        $(img).removeClass('img-selected');
    } else {
        // 选中
        selection.push(id);
        $(img).addClass('img-selected');
    }
    setAction();
}

function onSubmit() {
    $('#SelectedImages').val(selection.toString());
    $("#captchaForm").submit();
}
```

### 3. SubmitCaptcha 请求

**POST** `https://spain.blscn.cn/CHN/CaptchaPublic/SubmitCaptcha`

参数（form-urlencoded）:
```
SelectedImages=id1,id2,id3
Id=<from GenerateCaptcha hidden field>
Captcha=<from GenerateCaptcha hidden field>
```

成功响应:
```json
{"success":true,"captcha":"<CaptchaData Base64>","captchaId":"<Id>"}
```

失败响应:
```json
{"success":false,"error":"Invalid selection"}
```

### 4. CaptchaData 用途

`CaptchaData` 用于后续 **SendRegisterUserVerificationCode** 请求:
```
POST /CHN/account/SendRegisterUserVerificationCode?
    email=...&
    captchaData=<CaptchaData>&
    captchaId=<CaptchaId>
```

## 验证码流程

```
GET /CHN/account/RegisterUser
  → SecurityCode

GET /CHN/CaptchaPublic/GenerateCaptcha?data=<SecurityCode>
  → Captcha hidden field (长加密字符串)
  → Id hidden field
  → __RequestVerificationToken
  → 54 张 JPEG base64 图片 + 随机 div ID
  → box-label 问题标签（目标数字）

  (OCR 识别每张图中的数字)

POST /CHN/CaptchaPublic/SubmitCaptcha
  → SelectedImages=comma_separated_ids
  → Id
  → Captcha

  ← {"success":true,"captcha":"<CaptchaData>"}

POST /CHN/account/SendRegisterUserVerificationCode
  → captchaData=<CaptchaData>
  → captchaId=<CaptchaId>
  → email

  ← {"success":true,...}
```

## OCR 策略

1. **ddddocr**（已安装 v1.6.1）- 适合中文/数字混合场景
2. 图片为 JPEG，需识别图中显示的数字
3. 目标数字来自 `box-label` 文本
4. 匹配成功则选中对应 div ID

## 已知问题

- **IP 封禁**: 网站检测到非西班牙 IP 会快速封禁
- **OCR 准确率**: 数字识别可能有误差，可重试或用更高 beta 模型
- **时序**: Captcha/Id 字段有有效期，需在同一会话中使用
