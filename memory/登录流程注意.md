## 一、环境配置

### SSL 证书验证

**必须设置 `verify=False`**，否则 HTTPS 请求会被拒绝：

```python
import requests
import urllib3
urllib3.disable_warnings(urllib3.exceptions.InsecureRequestWarning)

session = requests.Session()
resp = session.get(url, verify=False)
```

### 代理配置

使用 Reqable 本地代理 (`127.0.0.1:9000`) 可以自动更换 IP：

```python
PROXY = "http://127.0.0.1:9000"
proxies = {"http": PROXY, "https": PROXY}
resp = session.get(url, proxies=proxies)
```

## 三、Step1: 获取登录页面

**GET** `/CHN/account/login`

### 提取关键字段

```python
# 从 login form 中提取
rvt = form.find("input", {"name": "__RequestVerificationToken"})["value"]
id_val = form.find("input", {"name": "Id"})["value"]
text_fields = [inp.get("name") for inp in form.find_all("input", type="text")]
```

### CSS display:none 解析（判断字段可见性）

```python
style_blocks = re.findall(r'<style[^>]*>(.*?)</style>', html, re.DOTALL)
css_text = '\n'.join(style_blocks)

display_none = set()
for cls_name, props in re.findall(r'\.([a-z0-9]+)\s*\{([^}]+)\}', css_text):
    if re.search(r'display\s*:\s*none', props):
        display_none.add(cls_name)

# 判断 form-group 是否隐藏
fg_classes = fg.get("class", [])
if isinstance(fg_classes, str):
    fg_classes = fg_classes.split()
hidden_by_css = any(c in display_none for c in fg_classes)
```

### Email 字段判断逻辑

- 遍历所有 text input，查找 label 包含 "Email" 的字段
- 检查父级 form-group 是否被 CSS display:none 隐藏
- 每次页面刷新，Email 字段的 name 是随机的

## 五、Step3: 获取验证码页面

**GET** `/CHN/newcaptcha/logincaptcha?data=<SecurityCode>`

### 页面结构

- 包含 54 张 base64 图片（6 组叠加）
- 9 个 grid 位置 (0,0) (0,110) (0,220) (110,0) ... (220,220)
- 每个位置有多张图片重叠，最终只显示 z-index 最高的

### CSS 解析

```python
class_info = {}   # class_name -> {left, top, z, display}
for cls_name, props in re.findall(r'\.([a-z0-9]+)\s*\{([^}]+)\}', css_text):
    info = {}
    m = re.search(r'left\s*:\s*(-?\d+)px', props);   info["left"]    = int(m.group(1)) if m else None
    m = re.search(r'top\s*:\s*(-?\d+)px',  props);   info["top"]     = int(m.group(1)) if m else None
    m = re.search(r'z-index\s*:\s*(\d+)',    props);   info["z"]       = int(m.group(1)) if m else None
    m = re.search(r'display\s*:\s*(\w+)',     props);   info["display"] = m.group(1)        if m else None
    class_info[cls_name] = info
```

### ⚠️ show()/hide() JS 调用解析（关键！）

有些 div 通过 jQuery 的 `.hide()` 方法隐藏，CSS 中没有 `display:none`：

```python
script_text = '\n'.join(style_blocks)
for block in re.findall(r'<script[^>]*>(.*?)</script>', html, re.DOTALL):
    script_text += '\n' + block

hide_ids = set()
for m in re.finditer(r"\$\(['\"]#?(\w+)['\"]\)\.(show|hide)\(\)", script_text):
    elem_id, action = m.group(1), m.group(2)
    if action == 'hide':
        hide_ids.add(elem_id)
```

### 图片可见性判断

```python
# 检查是否被 CSS display:none 隐藏
hidden_by_css = any(
    class_info.get(c, {}).get('display') == 'none'
    for c in classes
)
# 检查是否被 jQuery hide() 隐藏
hidden_by_js = div_id in hide_ids

if hidden_by_css or hidden_by_js:
    continue  # 跳过不可见的 div
```

### 每个位置取最高 z-index 的图片

```python
position_best = {}
for entry in img_entries:
    # ... 可见性检查 ...
    key = (left, top)
    if key not in position_best or z > position_best[key].get('_z', 0):
        position_best[key] = {"id": div_id, "src": entry["src"], "_z": z}
```

### 目标数字提取

box-label 通过 CSS z-index 堆叠，取 **z-index 最高** 的那个：

```python
label_entries = []
for m in re.finditer(r"Please select all boxes with number (\d+)", html):
    digit = m.group(1)
    # ... 计算 z-index ...
    if hidden:
        continue
    label_entries.append({"digit": digit, "z": z})

label_entries.sort(key=lambda x: x["z"], reverse=True)
target_digit = label_entries[0]["digit"] if label_entries else None
```

## ⚠️ 重要结论：OCR 不是问题关键

**OCR 识别率超级高，ddddocr 识别不可能是问题关键！**

当验证码提交失败时，**不要在 OCR 识别上浪费时间排查**。问题几乎肯定在：

1. **图片可见性判断** (最高优先级) - CSS display:none、jQuery show()/hide() 是否正确解析
2. **参数传递正确性** (高优先级) - SecurityCode、captchaId、RVT 是否正确

## 八、常见错误排查

| 错误 | 原因 | 解决方案 |
|------|------|----------|
| `SSL: CERTIFICATE_VERIFY_FAILED` | 未设置 `verify=False` | 添加 `verify=False` |
| Step2 返回 `err=` | 邮箱未注册或格式错误 | 使用真实邮箱 |
| Step3 返回 302 | SecurityCode 编码问题 | 保持原始 URL 编码 |
| 验证码提交失败 | **图片可见性判断错误** | 检查 CSS 和 JS 隐藏逻辑 |
| 验证码提交失败 | **参数来源错误** | 检查 captchaId/RVT 是否正确 |

---

## 九、问题排查优先级

| 优先级 | 问题类型 | 排查方向 |
|--------|----------|----------|
| 🔴 高 | 图片可见性 | CSS display:none、jQuery hide() 是否正确解析 |
| 🔴 高 | 参数来源 | captchaId 是否用 RegisterUser 页面的值 |
| 🟡 中 | 编码问题 | SecurityCode 是否保持原始 URL 编码 |
| 🟢 低 | OCR 识别 | 识别率极高，不需要排查 |
